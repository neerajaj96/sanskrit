# അനുബന്ധം ൨ — ഗീതാമൂലശ്ലോകങ്ങളിലെ പാഠാന്തരങ്ങൾ (രാമകണ്ഠൻ × ശങ്കരൻ)

രാമകണ്ഠപാഠവും [രാമകണ്ഠപാഠഃ] ശങ്കരപാഠവും [ശങ്കരപാഠഃ] തമ്മിലുള്ള വ്യത്യാസങ്ങൾ, അദ്ധ്യായം-ശ്ലോകം ക്രമത്തിൽ. പാഠങ്ങൾ വിവർത്തനം ചെയ്യാതെ മലയാളലിപിയിലേക്ക് ലിപ്യന്തരം മാത്രം ചെയ്തിരിക്കുന്നു; അദ്ധ്യായ/ശ്ലോക സംഖ്യകൾ അറബി അക്കങ്ങളിൽ. അച്ചടിയിൽ ഒറ്റവരിയായി ചേർന്നുപോയ ചില പാഠജോഡികൾ അതേപടി ഒറ്റക്കള്ളിയിൽ നൽകിയിരിക്കുന്നു; അദ്ധ്യായസംഖ്യകൾ അച്ചടിക്രമം പിന്തുടരുന്നു. ആകെ 131 പാഠാന്തരവരികൾ.
