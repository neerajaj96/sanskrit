# അനുബന്ധം ൧ — ശുദ്ധിപത്രം (അച്ചടിപിശകുകൾ തിരുത്തൽപ്പട്ടിക)

1943-ലെ നിർണ്ണയസാഗർ അച്ചടിയിലെ (പുറം 406–410) അശുദ്ധ-ശുദ്ധ പാഠങ്ങളുടെ പൂർണ്ണ പട്ടിക. തലക്കെട്ടുകൾ മലയാളത്തിലേക്ക് വിവർത്തനം ചെയ്തിരിക്കുന്നു; പാഠങ്ങൾ മലയാളലിപിയിലേക്ക് ലിപ്യന്തരം ചെയ്തിരിക്കുന്നു; പുറം/വരി സംഖ്യകൾ അറബി അക്കങ്ങളിൽ. ആകെ 110 തിരുത്തലുകൾ.
